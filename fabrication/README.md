# Fabrication Files

Add the exact package submitted to the fabrication/assembly supplier here. Preserve the
original ZIP unchanged and record its filename, board revision and SHA-256 in the build
record. Do not regenerate or rename files inside that original ZIP.

Extracted Gerbers, drill files, stackup notes, placement files and fab-submitted BOM may
be added separately, with their revision stated. Put later exports in a different revision
directory so they cannot accidentally be mistaken for the original manufactured package.

Remove private supplier correspondence and confirm file redistribution rights before
uploading. Keep assembly quotes, account details and order correspondence outside Git or
in the ignored root `private/` directory.
