# Editable Design Sources

Open `Lora_pi_Hat.kicad_pro` to work with the schematic and PCB. The PCB file reports
KiCad generator version 10.0; independent CAD opening, ERC/DRC and library completeness
have not been verified as part of this release.

The current PCB includes revised fuse pads that have not been fabricated. The original
working-board fabrication package is kept separately in `fabrication/`.
See [the release record](../RELEASE.md) before regenerating manufacturing outputs.
